# Marktlabor

Marketing spielerisch und datenbasiert lernen: Labore, Entscheidungsspiele und Wirtschaftssimulationen gegen KI-Konkurrenz, mit Tutorials, klickbarem Fachlexikon und Pixel-Szenen von Rom bis heute.

Öffnen: `index.html` im Browser. KI-Funktionen und Cloud-Spielstände laufen nur in der claude.ai-Version; lokal speichert die App im Browser.

Hinweise zur Struktur für die Weiterentwicklung stehen in `CLAUDE.md`.
